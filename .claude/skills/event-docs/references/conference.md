# Conferences & trade shows

Someone else's show; Attentive sponsors, exhibits, or speaks. Long runway — tasks start 15 weeks
out. The defining feature is a **second task list you do not control**: the exhibitor portal
deadlines, which carry real money (a missed logo deadline means paying for signage twice).

Reference event: **eTail West 2026, Feb 23–26, JW Marriott Palm Springs, $263,000.**

## Project Plan tabs

Conference plans sprawl, and tabs get added per activation. The eTail West plan ran 17 tabs. The
durable set:

| Tab | Contents |
| --- | --- |
| `Project Plan ` | Event Date, Venue, Budget, Objectives, KPIs, Description. Key Links includes Event Portal, Alliance Portal, Event Website, Invite List / Meeting Tracker / RSVPs, and the show's public URL. |
| `Timeline + Tasks` | Two stacked sections — see below. |
| `Budget Sandbox` | Working budget with a sponsorship-offset block off to the side (partner name, amount, Sold TRUE/FALSE). |
| `Itemized Budget` | Item, Estimated, Actual, Budget Owner, Notes. Budget Owner is how spend is split across Events / Brand / Events T&E. |
| `Final Budget` | Actuals for close-out: Estimated, Actual, Quoted, Status Notes, Invoicing Notes, Payment Status. |
| `Staffing & Passes` | Pass type (Speaker/Retailer/Delegate), name, Room Block, Villa, Arrival, Departure. |
| `Speakers` | Name, Company, Title, Travel Notes, Headshot / Bio, Speaker Portal. |
| `Sponsors` | Opportunity, partner, Contract (Signed/Sent), Logo, Splash Page. |
| `Hotel Room Block` | Rate, access code, cut-off date, named guests with emails and confirmation numbers. |
| `Printed Assets` | Description, QTY, Description/size, Tracking Number, Cost, Delivery Status, Notes. |
| `Shipping/Tracking` | Item, Qty, Tracking Information, Status. |
| `ROS` | Run of show, day by day: Time, Duration, Segment, Owner, Details/Notes. |
| `Vendor List` | Vendor, Details, Contact, Timings (load-in / start / breakdown). |
| `Car Schedule` | Per day: Time, # of Cars, Notes, Total Hours Used. |

Per-activation tabs get added by name — eTail West had `BMW`, `Rockwood`, `The Pit Stop`. Each
tracks that activation's own asset deadlines or attendee waivers. Add one per locked activation;
don't pre-create them for activations still under research.

## Timeline + Tasks — section two: Portal Deadlines

Below the first section, a second header row repeats (`Portal Deadlines | Status | Weeks Out |
Due Date | Notes`) and the portal deadlines follow. These are **set by the show, not by the
workback formula** — do not compute them. Pull the real dates from the exhibitor portal, the
sponsorship contract, or the show's emails, and put `TBD` where you cannot find one.

The recurring rows, with eTail West's weeks-out as a rough guide to ordering:

| Weeks Out | Deadline |
| --- | --- |
| 14 | Speaker Information, Headshot, Bio, presentation |
| 6 | Tabletop / Booth Logo Deadline |
| 6 | Company Logo, Description, Website, etc |
| 5 | Staff Registration |
| 4 | Hotel room block cut-off date |
| 1 | Tabletop / Booth Payment |
| 1 | Exhibitor Orders Due (AV, Internet, Lead retrieval) |
| 1 | Exhibition Activation |
| 1 | Secondary hotel room block cut off date |

When a portal deadline date is unknown, say so explicitly in the report — a missed portal
deadline is the most expensive failure mode for this event type, and a `TBD` sitting quietly in
a cell is not a warning.

## Objectives and KPIs

eTail West used: Strengthening Customer Relationships / Expand Customer Knowledge of Attentive /
Deepen Pipeline / Showcase Company Culture / Gain Feedback and Insights. Note **Deepen Pipeline**
rather than proprietary's "Drive New Pipeline" — conferences work existing pipe.

KPIs skewed to Number of Attendees and Attendee Feedback.

## Overview Doc shape

Same two-column Key Links table, but the links differ: Event Portal, Alliance Portal, Event
Website, the public show URL, Invite List / Meeting Tracker / RSVPs, Drive folder, Project Plan.

The Description is about the *show*, not the guest experience — what the conference is, who
attends, why Attentive is there. eTail West's: "eTail West is a major e-commerce conference and
event for retailers, brands, and solution providers that takes place annually in Palm Springs,
California. It features networking opportunities, educational sessions, and workshops to discuss
the latest trends, technologies, and strategies in online retail."

In place of Guest Experience, list the Attentive footprint: sponsorship inclusions, booth or
tabletop, speaking slot, ancillary events, and activations. That is what a colleague needs to
know to talk about the event.
