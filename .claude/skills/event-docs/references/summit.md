# Customer summits & roadshows

Attentive-run, multi-session, with an agenda, speakers and often a 1:1 meeting track. The Thread
series. Longest runway at 16 weeks, and the only type whose timeline carries **Phase** and
**Owner** columns — because the work genuinely splits across people (events, demand gen, brand,
partnerships) and needs sequencing, not just dates.

Reference event: **Thread NYC 2026** (16-week plan, phased, owner-assigned).

## Project Plan tabs

The most elaborate of the three. Thread NYC ran 28 tabs. The durable set:

| Tab | Contents |
| --- | --- |
| `Project Plan ` | Event Date, Venue, Budget, Objectives, KPIs, Description + Key Links. |
| `Timeline + Tasks` | Phase, Description, Status, Weeks Out, Due Date, Owner. |
| `Promo Tracker` / `Promo Calendar` | Email and comms cadence — the promotion engine for a registration-driven event. |
| `Budget Summary` | Roll-up. |
| `Budget Tracker` | Line items. Venue-comparison tabs (`Budget Comparison <Venue>`) appear during venue selection and can be left behind afterward. |
| `SessionsRountables` | Session title, abstract, speaker, title, time. (Tab name is misspelled in the real file — keep it if copying that template.) |
| `PartnershipsSponsors` | Partner participation, logos, contract status. |
| `Invites & RSVPs` | Invite list and RSVP state. |
| `Internal Attendees` | Which Attentive staff attend. |
| `Design Elements` | Brand deliverables. |
| `Printed Assets` | As other types. |
| `Vendor Tracking` / `Vendor ROS` | Vendors and their load-in/out schedule. |
| `SwagActivation` | Swag and onsite activations. |
| `ShippingTracking` | Item, qty, tracking, status. |
| `Shotlist` | Photo/video capture list. |
| `StaffingScheduling` | Who is working which shift. |
| `ROS` / `AV ROS` | Run of show, and the AV-specific cue sheet. |

Don't recreate all 28 for a new event. Start from the durable set above and add tabs as the
event acquires them — a venue-comparison tab is useful during selection and dead weight after.

Six phases. Keep the phase labels verbatim when copying an existing template, including the
misspelled `Infrastucture` — renaming it silently breaks any filter or pivot the planner built
on it. If creating a plan fresh rather than from the template, spell it correctly.

Phases: `Foundation / Strategy`, `Infrastucture`, `Marketing Launch`,
`Promotion/Partner Activation`, `Production & Logistics`, `Final Event Prep`, `Post Event`.

sessions), Carrie (partnerships). **Infer an owner only where a source names one.** Guessing who

and Salesforce, which the other two types do not.

## Objectives and KPIs

Summits are registration-driven, so KPIs lean on registration-to-attendance conversion, session
attendance and pipeline influenced. Source these from the kickoff rather than carrying forward.

## Overview Doc shape

Per the first task in the timeline, the Overview Doc for this type is explicitly "for all event
note capture" — it is a working document, not only an outward-facing summary. Give it the
standard header and Key Links table, then room for running notes: agenda-at-a-glance, speaker
list, and a notes section the team appends to through planning.
